# 🔐 Login & Registration System (C++)

## 📌 Description
This is a simple Login and Registration System built using C++.  
It uses file handling to store user data (username and password).

## 🚀 Features
- User Registration
- User Login
- Duplicate username check
- File handling using users.txt

## 🛠️ Technologies Used
- C++
- File Handling (fstream)

## ▶️ How to Run

### Step 1: Compile
g++ login.cpp -o login

### Step 2: Run
./login

## 📂 File Structure
- login.cpp → Main program
- users.txt → Stores user data

## ⚠️ Note
Passwords are stored in plain text (not secure).  
For real projects, use password hashing.
